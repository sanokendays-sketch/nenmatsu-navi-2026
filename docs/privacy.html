入力内容の扱い・利用上の案内

入力方法を選ぶ

回答はブラウザー内で処理します

給与額、本人・家族の氏名・住所・生年月日、勤務先、保険会社名、契約者や受取人の氏名などの回答を、アプリのサーバーへ送信しません。localStorage・Cookie・IndexedDBへの回答保存も行いません。回答はこのページを開いている間だけ保持し、再読み込みや終了で消えます。ただし、ご自身で「作業ファイルを保存」を押した場合は、回答と氏名等を含むJSONファイルを端末にダウンロードします。再開時はファイルをブラウザー内で読み込みます。作業ファイルはご自身だけが使える場所に保管し、不要になったら端末から削除してください。

サイトの配信について

GitHub Pagesで公開した場合、配信元のGitHubはセキュリティのために閲覧時のIPアドレスを記録します。これはアプリの回答送信とは別のアクセス記録です。

GitHubの公式説明（Data collection）

PDF・作業ファイル・外部リンク

PDF保存・印刷はブラウザーの印刷機能を使います。保存したPDFと作業ファイルには入力情報が含まれるため、共有先を確認してください。国税庁などの外部リンクを開くと、そのサイトへアクセスします。

対象と確認範囲

令和8年分、2026年12月1日以降の年末調整を想定しています。早期の年末調整には基準が異なる場合があり、このアプリで切り替えません。国税庁の公式サービスではありません。金額は回答に基づく記入候補です。確認事項は勤務先担当者などへ確認してください。

年税額、還付額、追加徴収額、住宅ローン控除額は計算しません。氏名等は任意入力できますが、個人番号・該当チェックなどの最終記入と確認が残ります。

「PCで用紙に入力」のPDF保存・印刷と、スマートフォンでの操作について、作成者から実ブラウザーで確認済みとの報告を受けています（報告日：2026年10月13日）。2026年10月13〜14日、公開ページで代表的な回答パターンの通し操作と作業ファイルの保存・再開を検証しました。全分岐の組合せは未確認です。

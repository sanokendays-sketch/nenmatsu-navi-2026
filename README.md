# 令和8年 年末調整おたすけナビ v3

年末調整の申告書を、一問ずつ答えながら準備する「やさしい記入ナビ」です。

- [最新版v3を開く](https://sanokendays-sketch.github.io/nenmatsu-navi-2026/)
- [従来のページ別v2を開く](https://sanokendays-sketch.github.io/nenmatsu-navi-2026/v2/)

## 使い方

1. 給与明細や控除証明書を用意し、質問に回答します。
2. 結果で「書く内容」「必要書類」「担当者への確認」を確認します。
3. 結果の下で氏名・住所・勤務先・家族情報を任意入力し、「名前・住所などを用紙へ反映する」を押します。
4. 用紙画像の金額と氏名を確認し、説明つき記入ガイド、数字入りの用紙記入例、保険の別紙明細をPDF保存・印刷します。

分からない金額は空欄と確認案内になります。個人番号・該当チェックなどは自分で確認・記入してください。住宅ローン用紙の自動完成、最終税額・還付額の計算は行いません。

## 入力内容の扱い

入力した給与・氏名・住所等はブラウザー内のメモリだけで扱い、アプリから保存・送信しません。再読み込み・終了で消えます。保存するPDFには入力内容が含まれます。GitHub Pages配信元のアクセス記録はアプリの回答送信と別です。[利用上の案内](docs/privacy.html)。

公開元はmainブランチの/docs。srcにソース、docsに公開ファイル、docs/v2に旧版があります。
Node.js 20以降でnpm run buildを実行すると、v3とv2のバンドルを生成します。依存パッケージの追加は不要です。公式画像・PDFは国税庁の原本です。

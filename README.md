# 令和8年 年末調整おたすけナビ

PC・スマートフォン・紙の申告書から、自分に合う入力方法を選べる記入ナビです。

- [入力方法を選ぶ](https://sanokendays-sketch.github.io/nenmatsu-navi-2026/)
- [PCで用紙に入力](https://sanokendays-sketch.github.io/nenmatsu-navi-2026/paper.html)
- [スマホで一問ずつ入力](https://sanokendays-sketch.github.io/nenmatsu-navi-2026/v3/)
- [紙を見ながら入力](https://sanokendays-sketch.github.io/nenmatsu-navi-2026/v2/)

## 「PCで用紙に入力」の使い方

1. 「家族・本人」「所得・控除」「保険料」から用紙を選び、色の枠を押します。
   初めての方は「上から順に答える」から、その用紙の未入力の欄を順に進められます。
2. 右側の質問へ回答すると、記入できる内容が用紙上に反映されます。枠には「未入力・入力中・入力済み・要確認」を表示します。
3. 途中でやめる場合は「作業ファイルを保存」を押し、再開時は「作業ファイルから再開」で読み込みます。
4. 「この用紙の未記入を確認してPDFにする」で空欄と確認事項を見ます。「この欄へ戻る」から修正できます。内容を確認してからPDF保存・印刷します。

[操作と確認範囲](V4_GUIDE.md)、[入力内容の扱い](docs/privacy.html)。

用紙は初期状態で画面幅に収まります。「用紙を大きく見る」で拡大し、「用紙全体を表示する」で戻します。狭い画面では、欄を選ぶと質問まで自動で移動します。

## 入力内容の扱い

回答はブラウザー内で処理し、アプリからサーバーへ送信しません。自動保存もしません。任意で保存するJSONの作業ファイルとPDFには、氏名・住所・給与・保険などの情報が含まれます。保管場所と共有先を確認し、不要になったファイルはご自身で削除してください。「反映して次へ」を押す前の質問欄の入力は作業ファイルに含まれません。

## 対象と限界

2026年12月1日以降の令和8年分年末調整を想定しています。国税庁の公式サービスではありません。用紙上の数字や文字は**記入例**であり、提出済みの完成申告書ではありません。個人番号、該当チェック、判定区分、計算途中欄などはご自身で確認してください。住宅ローン控除額、年税額、還付額、追加徴収額は計算しません。

公式用紙と記載例の根拠は [FORM_GUIDE_SOURCES.md](FORM_GUIDE_SOURCES.md) を参照してください。
